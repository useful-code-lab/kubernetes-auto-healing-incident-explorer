## 🔧 1. Обновляем систему

```bash
sudo apt update && sudo apt upgrade -y
```

---

## 🐳 2. Устанавливаем Docker (рекомендуется)

Minikube чаще всего используют с Docker как драйвером.

```bash
sudo apt install -y docker.io
sudo systemctl enable --now docker
```

Добавить себя в группу docker, чтобы не писать `sudo`:

```bash
sudo usermod -aG docker $USER
newgrp docker
```

Проверить:

```bash
docker --version
```

---

## 📦 3. Устанавливаем kubectl

```bash
sudo snap install kubectl --classic
```

Проверка:

```bash
kubectl version --client
```

---

## 🚀 4. Установка Minikube

Скачиваем последнюю версию:

```bash
curl -LO https://storage.googleapis.com/minikube/releases/latest/minikube-linux-amd64
```

Устанавливаем:

```bash
sudo install minikube-linux-amd64 /usr/local/bin/minikube
```

Проверка:

```bash
minikube version
```

---

## ▶️ 5. Запуск Minikube

С Docker драйвером:

```bash
minikube start --driver=docker
```

Если всё ок, увидим что кластер поднялся.

---

## 🧪 6. Проверка кластера

```bash
kubectl get nodes
```

Должен быть один node со статусом `Ready`.

---

## 🌐 7. Включить dashboard (по желанию)

```bash
minikube dashboard
```

---

## ⚡ Полезные команды

```bash
minikube status
minikube stop
minikube delete
```

---

## ❗ Частые проблемы

**1. Docker не запущен**

```bash
sudo systemctl start docker
```

**2. Недостаточно ресурсов**

```bash
minikube start --memory=4096 --cpus=2
```

**3. Ошибка с драйвером**
Попробуем явно указать:

```bash
minikube start --driver=docker
```
